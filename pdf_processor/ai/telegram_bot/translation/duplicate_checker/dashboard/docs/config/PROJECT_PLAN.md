# Question Bank AI

## Goal
Build an AI-powered Telegram bot that automatically extracts, translates, categorizes, deduplicates, and stores questions from PDFs, DOCX, TXT, Images, and other supported files into Supabase.

## Features
- PDF Upload
- OCR
- AI Translation
- MCQ Generation
- Duplicate Detection
- Subject Detection
- Chapter Detection
- Topic Detection
- Supabase Storage
- Telegram Bot
- Dashboard
